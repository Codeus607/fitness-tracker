# Fitness Exercises

The exercise list for the fitness tracker. Save it on the server as `exercises.md` (or keep it in your notes as `Fitness Exercises.md` and let the sync push it).

- `## Heading` = body part, `- Item` = exercise.
- Add `(bw)` after a name for bodyweight exercises (the weight you log is the extra weight only).
- Add `(sec)` for timed exercises (you log seconds instead of reps). Both: `(sec, bw)`.
- Renaming an exercise starts a fresh history under the new name, so add new names rather than renaming old ones.

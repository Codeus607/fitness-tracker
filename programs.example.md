# Fitness Programs

- `# Heading` = program, `## Heading` = day, `- Exercise: sets×reps` = exercise with its target.
- Exercise names must match `exercises.md` exactly. The target is optional.
- Targets: `4×6-8`, `3×12`, `3×max`, `3×30s` (an `x` works too).
- Plain text under a program or day heading is shown as a note.

# Full body 3 days

Three full-body sessions a week, rotate A → B → C.

## A
- BB Squat: 3×6-8
- BB Bench Press: 3×6-10
- BB Row: 3×8-12

## B
- BB Romanian DeadLift: 3×8-10
- BB Overhead Press: 3×8-10
- Pull-ups: 3×max

## C
- Machine Leg Press: 3×10-12
- DB Incline Bench Press: 3×10-12
- Pulldown (Any Grip): 3×10-12
